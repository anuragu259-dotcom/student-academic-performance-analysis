# Student Academic Performance and Dropout Risk Analysis

A data analytics project to analyze student academic performance and identify students who may be at risk of poor academic outcomes.

# Project Overview

This project uses student data to understand the relationship between academic performance, attendance, backlogs, self-motivation, stress, and family pressure.

# Tools and Technologies

- Python: Data analysis and visualization
- MySQL: SQL queries and student data analysis
- Excel: Data storage and analysis
- Power BI: Interactive dashboards and visual reports

# Key Analysis

- Attendance and academic performance
- Backlog analysis
- Department-wise performance
- Student risk classification
- Self-motivation and academic performance
- Family pressure and stress analysis
- Student support factors

# Project Files

- "Python_code_with_output.ipynb" — Python notebook
- "Student_performance_analysis.sql" — SQL queries
- "Student_Performance_Dashboard.pbip" — Power BI project
- "StudentData.csv" — Student dataset

# Objective

To help identify students who may need additional academic support through data-driven insights.
